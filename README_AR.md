# حزمة تسليم مشروع سعرلي

هذه الحزمة هي نسخة تسليم كاملة وآمنة من مشروع Sa3arly بتاريخ 13 أغسطس 2026.

## المحتويات

- `source/`: كود الموقع والواجهة والتصميم والأصول والخلفية والـAPI والـworkers والـscrapers وملفات Docker والبنية السحابية وGitHub Actions واختبارات المشروع وترحيلات قاعدة البيانات. النسخة مطابقة للـcommit `1862a6a1a00abea76e02d5508d424b1d0151e346`.
- `database/`: نسخة منطقية كاملة من بيانات الإنتاج بصيغة CSV، مأخوذة من PostgreSQL داخل snapshot ثابت للقراءة فقط. تتضمن manifest بأسماء كل الجداول وأعداد صفوفها، بالإضافة إلى توصيف حي للأعمدة والقيود والفهارس والـviews والـsequences.
- `operations/`: تقرير حالة الإيقاف وبيانات أحدث نسخة Cloud SQL احتياطية القابلة للاستعادة.
- `MANIFEST.sha256`: بصمات SHA-256 لكل ملفات الحزمة للتحقق من سلامتها.
- `DESIGN_REFERENCE.md`: مرجع رابط تصميم Figma الذي شاركه مالك المشروع.

## حالة الإنتاج عند التسليم

- الموقع العام لم يُغلق ويظل متاحًا للزوار.
- مجدولات تحديث الأسعار واكتشاف الكتالوج وإنهاء الدورات متوقفة.
- طوابير جمع الأسعار واكتشاف المنتجات متوقفة بدون حذف الأعمال المعلقة.
- خدمة التصدير المؤقتة حُذفت بعد اكتمال التصدير.
- تم تعطيل workflows المجدولة التي تبدأ أو تستعيد دورات الجمع.

## استعادة قاعدة البيانات

المسار الأدق لاستعادة البيئة نفسها هو استخدام نسخة Cloud SQL المشار إليها في `operations/sa3arly-cloud-sql-backup.json`. وللنقل إلى PostgreSQL جديد:

1. شغّل ترحيلات SQL الموجودة في `source/db/migrations/` بالترتيب.
2. فك `database/sa3arly-production-data.zip`.
3. راجع `metadata/manifest.json` و`metadata/schema.json` داخل ملف البيانات.
4. حمّل ملفات CSV لكل جدول باستخدام PostgreSQL `COPY` مع مراعاة العلاقات والتسلسلات.

## الأمان

لا تحتوي الحزمة على كلمات مرور أو ملفات `.env` فعلية أو مفاتيح خدمة أو tokens. يجب إنشاء الأسرار في البيئة الجديدة من ملفات المثال وتعليمات النشر الموجودة داخل `source/`.
