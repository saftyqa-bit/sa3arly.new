# سعرلي 0.4.11 — تشغيل وتحديث كل ساعة

هذا الإصدار مبني على `0.4.10-installmentguard` ويحافظ على إصلاحات المطابقة والأسعار والتقسيط السابقة.

## التغيير الجوهري

- تقسيم التشغيل الداخلي أصبح ساعة بساعة، وليس خانتين يوميًا.
- `REFRESH_CRON=0 * * * *` بتوقيت `Africa/Cairo`.
- `REFRESH_INTERVAL_MINUTES=60`.
- `FRESHNESS_MINUTES=75`.
- `STALE_AFTER_MINUTES=150`.
- اسم المجدول الفعلي `sa3arly-hourly-refresh`، بينما يبقى `sa3arly-12h-refresh` متوقفًا إن كان موجودًا.

## التشغيل الآمن

`ENABLE_HOURLY_COLLECTION.sh` لا يحذف مهام Cloud Tasks القديمة ولا يعيد إنشاء قاعدة البيانات. يوقف مصادر التشغيل، يبني إصدارًا ثابتًا، ينشر API وWorker مع الاحتفاظ بإعدادات Cloud Run القائمة، ينهي المهام القديمة، ثم يفعّل المجدول الساعي ويطلق دورة فورية.

عند أي خطأ أثناء القطع، يوقف الـQueue والـScheduler ويعيد حركة المرور إلى إصداري API وWorker السابقين.

## التحقق

بعد انتهاء الدورة الفورية شغّل `VERIFY_HOURLY_COLLECTION.sh`. وبعد مرور رأس ساعة جديد شغّل `MIN_SCHEDULER_SUCCESSES=2 bash VERIFY_HOURLY_COLLECTION.sh` للتأكد من ظهور طلب Scheduler ثانٍ في خانة زمنية مختلفة وتحرك أحدث توقيتات أسعار الكاش والتقسيط.
