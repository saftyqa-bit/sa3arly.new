# تقرير تنفيذ سعرلي — قاعدة Core V2

## نقطة البداية

تم استبدال ملفات مخطط PostgreSQL القديمة بخط أساس جديد ونظيف، مع الحفاظ على
Cloud Run وCloud Tasks وبنية الكاش والتقسيط وملفات البيانات الحالية.

## المنفذ فعليًا

### قاعدة البيانات

- Migration تأسيسية واحدة: `db/migrations/001_sa3arly_core_v2.sql`.
- فصل النطاقات إلى `reference` و`catalog` و`merchant` و`pricing` و`ingestion`
  و`operations` و`governance` و`analytics`.
- فصل عائلة المنتج والمنتج والنسخة، مع خصائص فنية typed ومعرّفات GTIN/SKU.
- فصل المتجر والبائع والـlisting وروابطه عن سجل الأسعار الحالي والتاريخي.
- تخزين الدولة على المتجر والعملة على العرض بدل تكرارهما داخل نسخة المنتج.
- إضافة قائمة مراجعة وسجل تدقيق.
- منع تكرار عد العروض في View المنتج الرئيسي.
- جعل مشاهدات الأسعار append-only وترقية الرصد المقبول فقط إلى السعر الحالي.
- إنشاء V2 بجانب جداول `public` القديمة، ثم نسخ بيانات الإنتاج داخل transaction
  واحدة والتحقق من المنتجات والمتاجر والروابط والأسعار قبل تحويل الخدمة.

### Backend

- إضافة وظائف الملخص والمراجعات والمنتجات وقرارات المراجعة إلى PostgreSQL.
- إضافة أربعة مسارات داخلية محمية بـ`X-Internal-Token`.
- اعتماد الربط يغير `review_status` إلى `approved`.
- رفض الربط يعطله منطقيًا بدل حذفه.
- قرار مرشح الكتالوج يحدّث حالته وملاحظاته.
- وضع Firestore القديم يعيد 503 واضحة لمسارات الإدارة بدل خطأ غير مفهوم.

### Frontend

- صفحة إدارة عربية RTL على `/admin`.
- حماية بواسطة هوية ChatGPT وقائمة `SA3ARLY_ADMIN_EMAILS`.
- الاتصال بالـAPI يتم من السيرفر فقط؛ التوكن لا يصل إلى المتصفح.
- مؤشرات الكتالوج والأسعار وجودة المطابقة.
- قائمة قرارات بشرية مع اعتماد ورفض وتجاهل.
- جدول المنتجات الرئيسية والنسخ والمتاجر والعروض.
- وضع Preview محلي فقط، وممنوع تلقائيًا في Production.

### النشر

- سكربت `DEPLOY_PRODUCT_CENTRIC_V0_6_0.sh` ينشئ Backup، يوقف التجميع مؤقتًا،
  يطبق Migration، ينشر API/Worker، يفحص الصحة، ويعيد حالات الـSchedulers
  والـQueues كما كانت.

## التحقق المنفذ

- `python -m compileall`: ناجح.
- 93 اختبار Python: ناجحة.
- اختبارات Migration ومسارات الإدارة الجديدة: ناجحة.
- فحص Syntax لملفات TypeScript/TSX الجديدة عبر TypeScript compiler: ناجح.
- فحص Syntax لسكربت النشر بواسطة `bash -n`: ناجح.
- إنشاء معاينة HTML وصورة PNG للوحة الإدارة: ناجح.

تم تشغيل اختبارات Python في بيئة لا تملك اتصالًا خارجيًا، لذلك استُخدمت
Test doubles محلية فقط لتمرير Imports الخاصة بـPsycopg وGoogle SDK؛ لم يتم
فتح اتصال حقيقي بقاعدة Production ولم يتم تنفيذ Migration عليها.

## قيد التحقق الحالي

لم يكتمل `npm ci`/build الكامل للواجهة داخل هذه البيئة لأن ملف القفل الأصلي
يشير إلى `vinext-0.0.50.tgz` وأعاد المصدر HTTP 404. لم أغير Framework أو
نسخة Vinext عشوائيًا حتى لا أكسر النسخة التي تعمل على منصة الاستضافة.
تم بدلًا من ذلك فحص Syntax وإنشاء Render فعلي للمعاينة باستخدام Chromium.

## ما لم يتم

- لم تُمس قاعدة Production.
- لم يتم نشر Revision جديدة على Cloud Run.
- لم يتم رفع التغييرات إلى GitHub لأن مستودع Sa3arly غير ظاهر في اتصال GitHub
  الحالي؛ الظاهر فقط مستودعات InstantGPA وTimeNivo وLinkTimer.
